# 查询、字段与标识

## 选择少量必要调用

复用本次会话已有的准确引用、授权和目标字段。不要将每次读取都展开为 owner → 全部 Projects → 全部字段 → 全部条目。只刷新缺失、冲突或已变化的部分；用于派发／验收的旧快照须核当前状态，普通查询不默认全组织轮询。

正式Project是任务总览和关联入口，详情通过对应Issue、执行及验收引用展开。回答当前进度时读阶段及本次所需依据；遇到聊天提报与看板矛盾，注明各自对象、版本和观察时间，交当前写者对账，不按最后一条消息直接改结论。查看源Issue正文／评论或原生运行使用相应工具；只有Projects工具时如实列明未取得内容，不把标题或阶段当完整任务记录。

| 所需结果 | 已知引用时 | 集合或引用未定时 |
| --- | --- | --- |
| Project 详情 | `projects_get / get_project` | `projects_list / list_projects`，带 owner_type 和必要 query |
| 字段定义／选项 | `get_project_field` | `list_project_fields` |
| 条目及当前进度 | `get_project_item` | `list_project_items`，只要所需字段和范围 |
| 项目状态更新正文 | `get_project_status_update` | `list_project_status_updates` |
| 保存的视图设置 | `get_project_view` | `list_project_views` |

方法名和必填参数按实际工具核对。这张导航不承诺所有宿主提供相同版本。

## 字段与完整性

- `list_project_fields`／`get_project_field`返回字段定义和选项，不是某条目的当前值。要回答任务进度，应读取对应item的所需字段，不能用“存在Status字段”或“包含Done选项”代替进度证据。
- 条目查询使用 `field_names` 或 `fields`，二选一。当前 schema 的默认结果可能只有标题；Status 缺失时先检查请求字段，不能推断未开始或空值。
- 目标字段名已明确且工具支持名称解析时，可直接用名称查询；需要枚举选项、消除重名或写入 ID 时再读目标项目的字段定义。
- 字段、选项及迭代 ID 仅在各自项目／字段范围使用；已有有效映射可复用，明确字段变化、名称歧义或解析失败时定向刷新，不每次查全表。
- 读取阶段值时同时保留源 Issue／PR 状态的含义。新入板条目可能已被默认工作流赋值；先读取实际基线，不预设字段为空，也不据此推断工作流已被验证。
- 同一筛选条件沿 `pageInfo.nextCursor` 前向翻页，直到没有下一页；只请求有限结果就如实报告范围。分页遍历不是服务端快照锁；观察到期间有变更时，只重核依赖它的判断。
- `list_projects` 的活动／关闭筛选影响可见结果；空列表只能描述当前调用身份、筛选及已完成覆盖内的结果。已知编号可直接读取，不能因活动列表为空否定已关闭项目。
- 为流程审计查询时，按指定项目、时间窗和来源说明覆盖；需要核对漏项就纳入约定范围的关闭、取消、迁出和未决派发，不能只查当前活动条目。仅有看板数据无法发现所有未登记执行；缺少原生执行清单或权限时标记覆盖不足，不能宣称全量无遗漏。
- 保存并回读视图的 filter 字符串，只证明设置值正确。若本次要求验证筛选结果，再核返回条目；不把设置回读当成内容覆盖验证。

## 不混用标识

| 参数／对象 | 含义 |
| --- | --- |
| `project_number` | owner 下的 Project 编号，非项目数据库 ID 或 node ID |
| `field_id` / `item_id` | 对应字段／项目条目的数值 ID |
| `view_id` / `status_update_id` | 对应对象返回的 node ID |
| 单选值 | 目标字段的选项名称或选项 ID，依当次方法支持选择 |
| 迭代值 | 该字段下某一周期的 ID，非迭代字段 ID、标题或日期 |
| 批量引用 | 每项使用一种支持的引用形式：条目 ID、node ID，或仓库＋Issue 编号 |

从有效任务引用或实际返回获得标识，核其归属；不猜 ID，不把不同类型的数字互换。批量返回可能只含 node ID／full_database_id，不要求每个结果都出现数字 item_id。

## 结果如何回报

普通查询回答用户所需内容即可；涉及交接、派发、验收或引用他人结果时，带目标、原观察时间、字段／筛选／分页覆盖及未取得项。转发保留原查询者和时间，不把转发时间算新查询。权限不足、字段未返回、空值和空列表分开说明；准确链接不自动授予接收方私有资源访问权。
