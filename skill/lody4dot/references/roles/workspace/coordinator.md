# G8 总协调（旧ID兼容入口）

`g8_coordinator`保留为既有查询和记录的兼容ID；通用组织职责已归独立[组织协作skill](../../../../organization-collaboration/SKILL.md)的`organization_lead`岗位，具体工作法见[总协调](../../../../organization-collaboration/references/organization-lead.md)。此处不再维护第二套组织规则，也不提供实际任命或通信权限。

本组织由公子确认云端Dot承担总负责人；实际参与者、项目负责人、汇报入口和当前任务仍来自有效关系记录，不能从旧角色名称推定。新岗位维护从组织skill开始，专业角色选择另行进行。

旧`render`或已保存Role不会自动装载新协议。迁移时先确认接收端可读取独立skill，再按已授权流程更新绑定与回执；在途原记录与历史V2.2保留，不由库更新自动改写。
