# 凡人项目适配

仅在显式选择`fanren-work`时使用。现有机器/配置绑定与项目根位置以负责人持有的正式接手入口及当前回执为准；本适配不改既有绑定、不授予换机或新计算后端。先核当前任务、授权、活动/UNKNOWN、精确下一步及冻结依赖清单；V2.2中的旧文档/Library版本是来源记录，不证明当前生产版本，不能自动更新代码、参数或CURRENT。

原著底本定事实，roadmap定讲述结构，人物/词典、声音合同、场景演绎保留各自唯一权威，以work_id和稳定实体ID消歧，旁白独立于韩立。关键因果、动机、知情、能力资源和伏笔功能守真，表达保持原创；不以搜索摘要、其他二创或模型记忆替代关键原文，也不把全文复制成新的提示词主库。

默认按阶段推进：原著/剧情候选→编剧与完整标注→独立全文/完整话轮QA→负责人冻结→获准音频/字幕制作→独立实物QA→保存回读与交付。首次合成前必须逐句、全文及完整话轮独立语义审查，抽样或结构检查不替代。文本、performance、source、annotations、receipt及活动绑定按实际生产合同核验，不发明格式。只有无依赖的研究、视觉和只读检查可并行，不默认所有角色同时生产。

新制作成品必须完整解码并实测不超过1200秒；12—18分钟只是建议。超时压稿或自然拆集，不变速、硬截或伪造时长。TTS、ASR及会加载模型的prepare遵守既有共享锁和状态锁，先收尾上一集依赖，不删锁、不抢占。容量包含原声、各处理层、完整解码、打包、回读及余量；预算未知不放行重负载。原音只读，新媒体输出新版本；断连先对账，仅补精确缺失，成功单元不重抽。

共享职责在本项目的界线：研究只补单点来源，原著事实/词典/roadmap候选由领域策划负责并交负责人合并；运行工程只修阻塞与工具链，声音生产者负责新音频/字幕/后期并接回生产。知识只交索引候选，不写正式状态。视觉按当前认可的节目/篇章层级、主规范15—18号和真实剧情人物作图，不将旧篇尺寸、封面改名或单篇样板泛化，不照搬官方演员/影视画面；获准图片嵌入不代表音频或发布获准。

QA须取得要求范围的原文、全稿、标注和全音轨。检查P0因果、知情资源、伏笔、声音身份、完整覆盖、实测时长/帧轴/SRT、双ASR疑点、局部动态、后期一次性配方、完整解码及保存恢复证据。ASR不是听审；真实听觉工具未知不得签听感/发音/自然度PASS，也不默认让公子逐句审批。按实际工具安排可核验审查，缺项如实保留。音频内容修订需回到相应完整话轮及绑定，不能只改字幕掩盖旧音轨。

获准归档后按精确恢复清单保存新字节，完整官方取回核版本、大小、SHA，包核成员及CRC/SHA；最后索引回执单独保存，不递归装包。保存、发送accepted、局部接受与全片听审分开记录。既有完工不授权下一篇，角色创建不包含媒体生产、清理或发布；原有硬门只由对应权威流程调整。
