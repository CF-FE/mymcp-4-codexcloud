# 诊断和恢复

先运行当前分发 README 对应的 doctor，并保留请求的 profile、退出码与脱敏失败类别。默认诊断不安装、不登录、不启停进程、不修改配置。stdout 为结构化结果时单独读取 stderr；不能丢掉原命令失败状态。

| 现象 | 下一项有意义的检查 | 不应自动进行的操作 |
| --- | --- | --- |
| 无 CLI 或版本不符 | 稳定入口、Node 要求、锁定版本、安装器结果 | 从任意 dist-tag 临时拉包替代 |
| 原生模块加载失败 | 明确包、ABI、平台、构建策略与下载目的地 | 关闭校验或对全部依赖放开脚本 |
| `LODY_CLI_TOKEN` 缺失 | 仅检查注入状态和当前任务配置 | 输出整个环境、请求聊天重交 token |
| 变量存在但未登录 | 通过显式认证工具核验授权路径 | 把占位符写入本地登录态、默认重复注册 |
| auth 缺状态目录或目录不安全 | 指定当前用户拥有的 `0700` 非符号链接目录；只在任务内准备身份状态 | 把登录态放进安装依赖目录或共享快照 |
| doctor 的 control/task/worker 被阻塞 | control 需显式 `--connect` 与已有私密状态；执行需独立真实证据 | 自动登录、启动 Agent，或把查询通过当任务能力通过 |
| 目录原始exit0但整段JSON解析失败 | 核对0.107.2是否仅夹带同workspace的Streams attach/detach诊断；使用随包工具的窄兼容并继续校验完整分页 | 任意截取最后一行、忽略未知日志、把失败当空目录 |
| workspace list 成功但机器/Role 查询超时 | 用明确 workspace 运行目录诊断；当前部署另需 Loro Streams 分片后缀，检查 CONNECT 403 与实际 hostname | 报告空资源、把登录成功当全部网络通过 |
| workspace/资源访问失败 | 实际身份、明确 ID、已有权限与选择器 | 静默换工作区、换身份或扩权 |
| daemon 未就绪 | 本机运行前提、运行中的版本、状态与脱敏日志 | 因远端在线就跳过本机检查 |
| Codex ACP initialize 报 SQLite/read-only | 核实确切运行版本、官方状态目录设置及宿主写入边界；单独 SQLite 目录不能保证 CODEX_HOME 的其余状态可写 | 改 HOME/CODEX_HOME、复制认证或反复猜参数绕过托管限制 |
| 网络 403、连接或观察失败 | 生效目的地规则、代理、CA、HTTP/长连接各自结果 | 绕过代理、关闭 TLS、立即重复发布环境 |
| 创建/聊天请求超时 | 已返回标识、operation、持久化会话状态和历史 | 未核实前重新创建或发送新消息 |
| Role 或 schedule 响应成功但未变化 | 是否只是确认提议、是否已由用户保存 | 自动当作配置已生效 |
| CLI 更新但行为仍旧 | 稳定 launcher、运行中 daemon/watchdog 的真实版本 | 把 npm 安装成功当运行版本已切换 |
| 未知参数或资料冲突 | 当前准确命令 `--help`、兼容版本与来源 | 猜参数、用内部接口绕过 |

每次重试都应检验新诊断或跟随实际状态变化。观察任务时选持续观察或适当快照，不建立无意义高频轮询。来源配置版本号不变本身不能证明当前网络规则未更新，应检查实际生效规则及请求结果。

需要日志时只取与故障相关的脱敏片段，不输出 token、完整环境、带签名 URL 或私密配置。恢复不删除用户已有登录态、daemon、项目或会话；仅撤销本任务拥有的测试配置与临时进程。

成功报告需说明修正了哪个具体前提、哪个受影响检查随后通过，以及仍未运行的能力。缺少底层 Agent 凭证、宿主加载或真实测试目标时，只阻塞对应能力，继续可以独立完成的资料与本地检查。
