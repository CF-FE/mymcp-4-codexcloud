3. **逐任务决定。** 原负责人明确哪些新任务采用新路线，哪些在途沿旧入口收尾或在明确检查点交接；唯一派发者和写者先核清。未知请求先对账，不能借迁移重派，也不自动切回Lody重做。
4. **停用独立执行。** 只有范围内活动执行、未知请求、写权、产物和遗留已完成或有效承接，并取得具体停用授权后，才处理旧服务、角色、保存环境、凭证或资源。旧Lody专属验收可按负责人决定记“不再计划／被替代”，不能为了退出强行重验或记成通过。

本轮完成条件是：清单和资料可取得、来源／闭包可核、接收方明确已读与采用类别、未决事实有原责任方和下一动作。它不要求本轮安装Herdr、建立消息服务、迁移看板或证明业务替换完成。源仓保留历史与恢复入口；关闭仓库、清理旧包或删除资料均不是本次交接动作。
