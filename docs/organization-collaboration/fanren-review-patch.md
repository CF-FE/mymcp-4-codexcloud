# 凡人项目产物复核：合并补丁示例

这是[通用产物就地复核协议](../../skill/organization-collaboration/references/execution-and-review.md#产物就地复核)的音频项目适配，不是通用skill的新职责来源。真实人员、会话、路径及任职版本只写入目标项目的正式记录。

## 应用边界

目标为win-work的`D:\fanren-work\docs\产物就地独立复核与结果回传.md`。公子转交Dot的回读说明：该文件和项目`AGENTS.md`仍为此前版本，既有入口在`AGENTS.md`第12行，新条款尚未落盘。本地已检查注册项目和`/Users/ghy/work`下同名文件，未找到目标checkout，也未取得远端原文；因此这里提供按章节合并的内容补丁，不伪造可直接`git apply`的上下文diff，不宣称win-work已同步。

目标执行端应用前先查看工作区状态及两份原文。保留既有授权、生产阶段、冻结要求和无关内容，将下节内容并入对应职责、检查和回执章节；同义条款合并，旧的“必须先上传云端才能验收”等冲突文字按新授权修正。`AGENTS.md`若已有正确指向该文档的入口，保留即可，不重复添加；仅在入口缺失或错误时修正链接。不得触发音频生产、发布、登录或系统安装。

## 合并到项目规范的内容

项目采用组织协议1.2.0的产物复核规则；实际采用版本、协议读取入口、正式负责人身份与任命依据在项目记录中填写。不要把角色库适配ID当作已任命负责人。负责人未绑定时记待确认，已授权且不依赖该身份的检查可继续，最终项目验收保持待确认。

负责人默认组织复核并作最终验收，可亲自检查或委派具备条件的检查者，最终责任不转移。制作自检、质量复核、负责人验收分列。独立检查者须未参与该版本制作或修订且实际核对证据；负责人兼任制作时，关键质量项另派复核。低风险小改优先复用合适的现有会话，不强制新增会话。

WAV默认在产物所在端复核，报告先交负责人；云端Dot接收结论、跟进阻塞，不要求收到WAV才验收，也不重复审批。确需跨端传输时核用途、访问和授权；只收到远端报告时写明报告来源，不能声称已亲自听辨。

每次检查绑定项目／集次、精确版本、所在端及路径、字节大小、时长、SHA-256、关联台本／字幕版本、检查者及时间。无法取得的属性明确未取得。文件内容变化后，旧结论不能直接沿用。

| 检查类 | 记录要求 |
| --- | --- |
| 技术检测 | 实际工具、格式与完整性检测结果及覆盖；波形正常或文件可读不能证明听感合格 |
| 内容核对 | 对照的台本／字幕版本、实际核对范围、漏字错字等有证据的问题 |
| 实际听辨 | 所用听辨接口、实际播放检查的时间段及方法；抽听不能写成全片听辨通过，自动检测不能替代实际听辨 |

每个检查项记“是否必验、方法与覆盖、通过／不通过／未验、证据”。找不到文件、无访问或缺听辨接口记未验及验收阻塞，不写成已确认的音频缺陷。必验项未验或存在阻断问题时，不得宣称成品验收通过。

问题记录时间码、证据、严重程度、阻断性、修订要求和责任方。修订后绑定新版本，复查问题片段及相邻衔接；换声线、全局处理、重新拼接等扩大到受影响范围，必要时全量回归。经差异核对后可明确限定范围复用未受影响证据，不能直接复用旧版整体验收。

回执使用组织协议的“产物复核与验收回执”：版本标识；检查者及岗位／独立性；方法与覆盖；制作自检、质量复核各项结论；问题及修订回归；未验项；负责人最终验收；回传来源与送达状态。每个卡点写清精确缺项、下一责任人、动作和解除证据。正式负责人未知时不能把Dot、制作端或任务创建者自动填为验收人。

## 合并后的检查与交回

只做规范检查和场景走查：WAV不上传仍可本端复核；QA或Dot代建不改变验收归属；缺听辨或文件不能通过；新版本不能沿用旧版整体通过；自检不能冒充独立复核且小改不强制新会话；负责人未绑定不能伪造任命或验收。

交回两文件的实际路径、采用协议／内容版本、差异摘要、场景结论、未解决项及提交SHA（若提交）。保留“项目文档已修改”“目标会话已读取”“实际音频已复核”三种独立证据。本补丁没有音频通过结论；临时缺文件、缺接口等运行现状应记在对应任务，不能写成永久规则。
