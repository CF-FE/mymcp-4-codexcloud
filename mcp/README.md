# MCP 服务

每个服务使用独立目录 `mcp/<id>/`，保存服务源码、该服务的依赖声明和锁文件，以及必要的测试与配置示例。`<id>` 使用小写字母、数字和连字符。

每个服务的 `README.md` 至少说明：

- 服务提供的能力，以及适用的运行平台。
- 运行时版本、安装和启动命令、命令的工作目录。
- 使用的传输方式、停止方法，以及所需外部服务。
- 必需环境变量的名称和用途、网络目的地；不记录凭证值。
- 能验证真实行为的请求或测试，以及预期结果。

当前没有服务条目，因此不指定 Node、Python 或其他运行时，也没有顶层依赖管理器。

服务实现不依赖 `plugin/` 的打包目录。多个插件使用同一服务时，均引用这里的源码，避免复制后分别维护。

云端可运行性需要在实际环境中验证。依赖本地桌面、浏览器、原生应用或其他平台能力的服务，必须明确其限制，不能仅凭进程启动就标记为可用。
