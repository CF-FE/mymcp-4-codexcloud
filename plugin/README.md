# Plugins

每个插件使用独立目录 `plugin/<id>/`，负责组合能力和定义分发方式。`<id>` 使用小写字母、数字和连字符。

每个插件的 `README.md` 至少说明：

- 插件用途及目标 Codex 环境。
- 组合的 MCP、skills 及其仓库相对路径；没有某类能力时明确写出。
- 必需配置、外部服务和网络目的地。
- 经过核实的打包与安装方式，以及执行命令的工作目录。
- 能验证安装结果、工具调用或技能加载的操作与预期行为。

实际清单文件遵循目标平台已核实的格式。这里暂不创建占位清单，也不把自定义字段伪装为 Codex 官方配置。

开发时引用 `mcp/` 和 `skill/` 中的能力源码；打包时按照平台要求收集文件，得到包含必要资源的产物。不要依赖指向包外的符号链接。允许构建过程生成文件副本，但这些副本不应成为第二份手工维护的源码。

插件可只组合 skills、只组合 MCP，也可同时组合两者。如果原插件依赖内部文件布局，先保留它的完整目录，再通过实际安装验证后拆分；不为了符合目录分类而先破坏已有插件。

当前没有插件条目。首个插件导入后，再确定是否需要共享打包工具或插件市场索引。
